1. AUTHENTICATION & SESSION APIS
   Associated Pages: /signin, /signup, /login
================================================================================

1.1 POST /api/v1/auth/login
    • Description: Authenticate user with credentials and return JWT session token.
    • Request Body:
      {
        "email": "user@nletacrm.com",
        "password": "SecurePassword123"
      }
    • Response (200 OK):
      {
        "success": true,
        "token": "eyJhbGciOiJIUzI1NiIsIn...",
        "user": {
          "id": "USR-101",
          "fullName": "Admin User",
          "email": "user@nletacrm.com",
          "role": "Super Admin"
        }
      }

1.2 POST /api/v1/auth/register
    • Description: Register a new system account.
    • Request Body:
      {
        "fullName": "Jane Doe",
        "email": "jane@nletacrm.com",
        "password": "SecurePassword123",
        "role": "Sales Representative"
      }
    • Response (201 Created):
      {
        "success": true,
        "message": "Account created successfully",
        "token": "eyJhbGciOiJIUzI1NiIsIn...",
        "user": { "id": "USR-102", "fullName": "Jane Doe", "email": "jane@nletacrm.com" }
      }

1.3 POST /api/v1/auth/logout
    • Description: Invalidate token and terminate current session.
    • Headers: Authorization: Bearer <token>
    • Response (200 OK): { "success": true, "message": "Logged out successfully" }

1.4 GET /api/v1/auth/me
    • Description: Get currently logged-in user profile from token.
    • Response (200 OK):
      { "id": "USR-101", "fullName": "Admin User", "email": "admin@nletacrm.com", "role": "Super Admin" }
